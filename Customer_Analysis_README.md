# Customer Analysis Project

## Project Overview

This project focuses on Customer Purchase Analysis using Python, SQL, and Power BI. The goal is to transform raw customer data into meaningful business insights through data cleaning, SQL-based analysis, and interactive dashboard visualizations.

---

## Technologies Used

- Python
- Pandas
- NumPy
- SQL
- Power BI
- Data Visualization

---

## Project Workflow

1. Data Collection
2. Data Cleaning using Python
3. SQL-Based Customer Analysis
4. Dashboard Development using Power BI
5. Business Insight Generation

---

## Key Features

### Data Cleaning
- Missing value handling
- Data preprocessing
- Data validation
- Exploratory Data Analysis (EDA)

### SQL Analysis
- Customer purchase analysis
- Category-wise sales analysis
- Location-wise analysis
- Revenue calculations
- Business reporting queries

### Power BI Dashboard
- Interactive filters
- Category analysis
- Gender analysis
- Location analysis
- Payment method analysis
- Purchase trend visualization
